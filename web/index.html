How this actually works

A real Lua VM, in JS

Fengari isn't a Lua-to-JS transpiler — it's a line-for-line port of the PUC-Rio Lua 5.3 VM. The obfuscator's compiler, parser, and code generator run as actual Lua bytecode, executing inside that VM, inside your tab.

Self-verifying output

The Medium and Strong presets use a step (Vmify + ConstantArray) that has a known, non-deterministic upstream bug (#155, #18). Fengatheus actually executes its own output in a sandboxed VM before showing it to you, and retries with a forced fresh seed if it hits that bug.

Nothing leaves your browser

There is no backend. This is a static site. Your source code, any file you attach, and the obfuscated result never touch a network request.
